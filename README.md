## GitHub Pages’da ochish

1. GitHub’da yangi repository yarating, masalan `sevinch-portfolio`.
2. `index.html` va `README.md` fayllarini yuklang (**Add file → Upload files**).
3. **Settings → Pages** bo‘limiga o‘ting.
4. **Source** qismida `Deploy from a branch`, branch sifatida `main` va `/ (root)` ni tanlang, so‘ng **Save** tugmasini bosing.
5. 1–2 daqiqadan so‘ng sayt shu manzilda ochiladi: `https://<username>.github.io/sevinch-portfolio/`
